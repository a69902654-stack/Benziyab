# ⛽ Benziyab

> Smart fuel station search, comparison, and navigation platform

**Benziyab** is a smart platform designed to help users find nearby fuel stations and choose the most suitable option based on distance, estimated arrival time, fuel type, station traffic, pricing, and online payment availability.

---

## ✨ Features

### 🗺️ Smart Map

- Display fuel stations on the map
- Show the user's current location
- Display the recommended route to a station
- Show distance and estimated arrival time
- View detailed information about each station

### ⛽ Fuel Type Filtering

Users can filter stations based on the available fuel type:

- Premium Gasoline
- Regular Gasoline
- CNG
- Other fuel types

### 🔎 Station Search

Users can search for fuel stations by:

- Station name
- Street
- Neighborhood
- Area or district

### 🚦 Traffic & Queue Status

The approximate traffic and queue status of each station is displayed:

- 🟢 Low
- 🟡 Moderate
- 🔴 Busy

This allows users to consider not only the distance to a station, but also its current queue and traffic conditions.

### 💳 Online Payment

Stations that support online payment are clearly marked, allowing users to identify available payment options before choosing a destination.

### 💰 Fuel Price

Fuel prices are displayed for each station, allowing users to check the estimated cost before selecting a station.

### 🧭 Navigation

For each fuel station, the application can display:

- Distance to destination
- Estimated arrival time
- Approximate route speed
- Route on the map
